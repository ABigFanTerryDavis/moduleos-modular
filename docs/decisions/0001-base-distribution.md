# Decision 0001: Base distribution

- **Status:** Accepted
- **Decision:** ModuleOS Modular 0.0.1 will be based directly on Ubuntu 24.04 LTS.

## Context

Zorin OS 18.1 and Ubuntu 24.04 LTS were previously discussed as possible foundations. The project owner chose Ubuntu 24.04 LTS directly for ModuleOS Modular 0.0.1.

## Consequences

- The repository and project are independent from ALI Linux.
- Ubuntu 24.04 LTS is the upstream baseline for future implementation work.
- This decision does not choose a desktop environment, package set, image-building system, hardware target, or branding approach; those remain open.
