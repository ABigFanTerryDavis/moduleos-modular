# ModuleOS Modular

ModuleOS is a Linux distribution family. **Modular** is its first variant.

> **Status:** 0.0.1 project bootstrap. This repository is not an installable operating-system image yet.

## Direction

- **Variant:** ModuleOS Modular
- **Version:** 0.0.1
- **Upstream base:** Ubuntu 24.04 LTS, selected directly
- **Project boundary:** This is a new, independent project; it is not ALI Linux.

The exact meaning of “modular,” target users and hardware, desktop experience, package selection, and image-building approach have not been decided. The project will document those decisions before treating them as implementation requirements.

## 0.0.1 focus

This first milestone establishes the project identity and records its upstream base. The next step is to define the initial product and technical specification, then choose a reproducible image-building approach and produce a testable prototype.

See [the roadmap](docs/roadmap.md) and [the base-distribution decision](docs/decisions/0001-base-distribution.md).

## Build status

There is no build system or downloadable image in this milestone. Build instructions will be added after the image-generation approach is selected.
